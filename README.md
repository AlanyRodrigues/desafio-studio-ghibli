Este projeto foi desenvolvido como parte de um desafio do curso FrontCode, com o objetivo de criar uma Landing Page responsiva inspirada no universo do Studio Ghibli.

Apesar de ser um projeto simples, ele foi essencial para aprimorar minhas habilidades em responsividade, organização de layout e desenvolvimento front-end. 
Além do aprendizado técnico, também foi uma experiência muito divertida e criativa de desenvolver.

Link para acesso web: https://alanyrodrigues.github.io/desafio-studio-ghibli/
